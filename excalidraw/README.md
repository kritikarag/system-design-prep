# Excalidraw diagrams

After each mock, export the board from excalidraw.com and drop the files here:

- **File → Save to… (.excalidraw)** → `day-NN-<topic>.excalidraw` (editable source)
- **Export image → PNG** → also save a copy as `mocks/day-NN-<topic>/my-diagram.png` so it shows on that day's page

Anything placed in this folder is committed and pushed with the next sync.
